# Shorboporisheba - Home Service Platform

## Overview

Shorboporisheba is a comprehensive web-based platform that connects customers with skilled service providers for various household services. Built with PHP, MySQL, and modern web technologies, it serves as a bridge between service seekers and providers.

## Features

### For Customers

- User-friendly dashboard
- Service request posting system
- Direct service booking
- Secure wallet integration
- Support ticket system
- Profile management
- Service provider ratings & reviews
- Real-time chat system

### For Service Providers

- Professional profile creation
- Service request management
- Real-time job notifications
- Payment tracking
- Customer communication system
- Real-time chat system

## Technology Stack

- Frontend: HTML5, CSS3, JavaScript
- Backend: PHP
- Database: MySQL
- Server: XAMPP

## Project Structure

```
ShorboporiSheba/
├── Cdashboard.php      # Customer dashboard
├── post.php            # Service post creation
├── service_request.html # Direct service request
├── support.php         # Customer support
├── wallet.php          # Wallet management
├── profile.php         # User profile
├── logout.php          # Session management
└── Images/             # Asset directory
```

## Installation

1. Install XAMPP
2. Clone repository to `htdocs` folder
3. Import database
4. Configure database connection
5. Access via localhost/ShorboporiSheba
